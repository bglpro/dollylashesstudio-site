# DollyLashesStudio

Site vitrine — React + Vite + Tailwind, déployé sur Vercel.

## Développement
npm install && npm run dev

## Où modifier quoi
- Liens, contacts, clés : src/config/site.js
- Couleurs et typo : src/theme.js
- Formations : src/trainings.js
- Prestations du carrousel : src/SpotlightCarousel.jsx (SLIDES)
- Questions fréquentes : src/FAQs.jsx (DEFAULT_ITEMS)

## Médias
Vidéos et images dans public/ — compresser avant d'ajouter (ffmpeg, CRF 28, 1280px).
